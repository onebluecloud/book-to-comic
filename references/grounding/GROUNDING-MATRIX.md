# 改编约束矩阵（grounding matrix）

> 一本书改编成漫画前，先回答一个问题：**这本书的世界被什么约束？** 七个维度各打 0-5 分，
> 分数决定哪些考据清单被激活。这不是文学价值评分，是"改编时必须尊重原著的强度分布"。
> plan 阶段由宿主写 `planning/grounding_profile.json`（schema 见 `schemas/grounding_profile.schema.json`）。

## 评分标尺（统一）

0=无关 · 1=弱相关 · 2=可选参考 · 3=**必须纳入常规考据** · 4=**逐项复核并留证** · 5=原则上不得改动。
**≥3 激活对应考据清单；≥4 强制复核**（个人创作场景=写进 adaptation brief 并在发布前人工确认，不设法务/顾问流程）。

## 七维定义与触发信号

| 维度 key | 约束什么 | 高分书型触发信号 | 考据重点（激活项） |
|---|---|---|---|
| `historical` 史实 | 现实世界/真实历史/地理/制度/人物/时代物质条件 | 历史、传记、回忆录、纪实、历史小说、古诗文 | 时代标记、阶层与职业、服饰器物建筑、制度礼法、地理空间、称谓语体、技术条件、真实事件链 |
| `textual` 文本 | 原文明写的设定/关系/规则/情节节点/时间线 | 奇幻、科幻、推理、系列小说、儿童文学、强设定 IP | 明确设定（外貌/物件/规则）、人物关系动机、能力边界、世界法则、时间线、标志场景物件、叙述结构、版本差异 |
| `conceptual` 概念 | 核心命题/概念定义/论证链/隐喻/价值判断 | 哲学、社科、方法论、理论书、寓言 | 核心命题、概念定义、论证链、因果与价值判断、核心隐喻、反例与限定条件、术语系统、论述重心 |
| `experiential` 经验 | 情绪基调/意象系统/节奏/视角/留白/余韵 | 文学小说、诗歌、日记、书信体、意识流、创伤叙事 | 情绪基调、意象系统、叙事节奏、视角与焦点、声音感语体、身体经验、留白密度、结尾余韵 |
| `procedural` 事实与程序 | 事实正确性/步骤顺序/参数剂量/安全边界 | 科普、医学、法律、编程、烹饪、教材、操作指南 | 事实准确性、流程顺序、参数剂量、术语规范、安全边界、可复现性、工具条件、结果解释 |
| `rights` 法权与人格 | 版权/改编权/完整权/现实人物肖像名誉隐私 | 在版权期作品、授权 IP、现实人物、回忆录、新闻 | **个人场景裁剪版：`copyright_status` 必填（public_domain / in_copyright / licensed）；in_copyright 且无授权 → 发布前人工确认，官方活动/放大镜场景优先换公版**（《活着》换课本古诗文的实战规则） |
| `cultural` 文化语境与受众契约 | 宗教神圣性/传统文化/经典公共记忆/年龄受众/粉丝惯例 | 圣典、神话、经典名著、儿童书、民族文化叙事 | 宗教与神圣性、经典/国民记忆、年龄与读者契约、集体创伤与纪念伦理、地域族群刻板化、本地化边界 |

## 冲突优先级四规则（改编中两种"忠于"打架时）

1. **硬法优先**：`rights` 高分且未解决 → 先解决合法性（换公版/取得授权），再谈艺术处理。
2. **高后果错误优先**：会造成现实认知伤害的改动（医学/法律/科学/史实误导），`procedural`/`historical` 压过节奏与娱乐性。
3. **明文高于推断**：原文明确写出的 > 从氛围/常识推断的。**实战案例：《桃花源记》"男女衣着，悉如外人"——史实推断说秦人晋人服饰应不同，但原文明写相同，文本约束赢。禁止"改得更合理"。**
4. **保核不保壳**：冲突不可避免时，保高分维度的"核"，允许低分维度的"壳"做媒介翻译（可以压缩旁白，不能改掉第一人称见证性质；可以重构图示，不能把概念讲反）。

原文内部的矛盾（如"隔绝五百年而衣着如外人"）**登记进 profile 的 `contradiction_register`，不许修复**——这些矛盾本身常是内容金矿。

## 与执行层的关系

- 打分是调度：`historical >= 3` → `character_bible` 的主要角色必须带 `social_class` + `class_evidence` + `wardrobe_evidence`（原文/教材注释依据），`environment_bible` 带 `era_markers`；字段带 `factuality`（`source_fact` 原文明写 / `inferred` 合理推断 / `invented` 纯创作），**不许把 invented 冒充考据**。
- `textual >= 3` → `concept_units`/`source_refs` 链路（已有闸门）按严格口径执行；多时代同框时 profile 写 `era_delta`（显式声明差异，或显式声明"原文说没差异"）。
- 闸门 `validate-grounding` 检查：profile 存在、高分维度有依据句、rights/cultural ≥4 时输出发布前人工确认提示。旧项目无 profile 自动跳过（兼容）。

# 统一 Art Direction System

## 1. 风格不是一个形容词

一个可靠的漫画风格至少包含以下轴：

```text
tradition / format / medium
realism / anatomy / face geometry
shape language / silhouette
line / ink / value
color / lighting / texture
character / environment / props
camera / panel rhythm / transitions
lettering / safe zones
provider-specific generation controls
style-specific QA gates
```

当前九个 ID 有的代表地域传统，有的代表媒介，有的代表出版格式。工程上不需要删除它们，但必须把它们当作“入口预设”，再展开为统一字段。

## 2. 自动生成 Art Bible

用户只输入书名时，系统在内部自动完成：

1. 从书籍内容形成 `art_brief`：时代、地点、受众、情绪范围、动作强度、抽象程度、平台。
2. 使用 `style_selection_matrix.json` 对九种风格评分。
3. 选定一个 `style_id` 和一个 `variant_id`，不要求用户中途确认。
4. 从预设生成 Style Bible。
5. 生成 Character Bible、Environment Bible、Prop Bible、Color Script、Shot Plan 和 Lettering Plan。
6. 先生成角色定妆和关键场景参考，再生成正式分镜。
7. 所有正式面板通过风格专属 QA 后才能进入最终合成。

## 3. Style Lock

一话开始正式出图后，以下字段成为不可静默修改的视觉合同：

- 角色脸部几何、年龄、体型和肤色；
- 发型大形、服装层级和标志道具；
- 线条粗细规律、黑白/颜色系统和材质处理；
- 反复场景的平面关系和视觉锚点；
- 关键道具的轮廓、材料和状态；
- 镜头语言和版式；
- 字艺类型和安全区。

重生成只能修正错误，不能把已经锁定的方向“优化”为另一种风格。

## 4. 参考资产分工

```text
identity_reference      负责人物身份
style_reference         负责线、色、材质和完成度
environment_reference   负责空间、建筑和重复场景
prop_reference          负责关键物件
composition_reference   负责镜头、动作和画面分配
```

不要把全部信息压成一张拼贴图，也不要只依赖 seed。图像模型仍可能发生角色一致性和精确构图偏差，因此应优先在已经锁定的参考图基础上做编辑式生成，并通过自动 QA 重试。[S23]

## 5. 生产层级

### 全局层

- `style_id`
- `variant_id`
- `style_lock`
- `color_script`
- `lettering`

### 角色层

- 轮廓和主形状；
- 面部几何；
- 比例；
- 服装层；
- 材质；
- 表情和姿态；
- 不可变化项。

### 场景层

- 年代、地域、建筑和文化；
- 房间或地点平面关系；
- 固定锚点；
- 光源；
- 材料；
- 不同景别的细节级别。

### 道具层

- 所有者；
- 剧情功能；
- 轮廓；
- 构造；
- 材料；
- 使用磨损；
- 状态变化；
- 与手部的交互。

### 面板层

- 出场人物；
- 场景和时间；
- 镜头；
- 动作和情绪；
- 关键道具状态；
- 前中后景；
- 文字安全区；
- 与前后格连续性。

## 6. 三值与缩略图原则

所有风格即使是全彩，也必须先通过黑白缩略图：

- 主体和背景是否分离；
- 焦点是否唯一；
- 人物轮廓是否可读；
- 关键道具是否被看见；
- 多格浏览时黑白密度是否有节奏。

页面构图在读者开始阅读细节前就已经传递风格和节奏，因此版式不是后处理装饰。[S24]

## 7. 精美度不是堆细节

发布级画面先通过这些可检查项，再谈细化：

- 3 秒焦点：手机缩略尺寸下能看出主角、主动作和关键道具；
- 唯一焦点：背景、道具和特效不能和主体抢第一眼；
- 剪影可读：主角涂黑后仍能看出姿态、情绪方向或身份特征；
- 角色记忆点：每个常驻角色至少有一个主吸引轴、两个视觉记忆特征和一个身体习惯；
- 情绪钉子镜头：每话至少一格能被读者记住的动作/道具/身体反应组合；
- 材质区分：皮肤、头发、布料、金属、木头、纸张不能全用同一种边缘、高光和纹理逻辑；
- 效果克制：关掉发光、粒子、轮廓光后，主体和动作仍然成立。

不要把“高质量”写成空泛 prompt。必须落成 `focal_point`, `action_vector`, `negative_space`, `main_light`, `material_words`, `character_memory_features` 等具体字段或 QA 记录。

## 8. 背景密度原则

- 建立镜头：高信息，说明时间、地点和社会语境；
- 对话中景：中等信息，保持空间锚点；
- 情绪近景：低信息，让脸、手和关键道具成为焦点；
- 动作格：背景线和纹理沿动作方向组织；
- 反应格：允许抽象或留白，但不能让地点连续性丢失。

专业漫画背景应提前规划反复地点的平面关系，以保持门窗、家具和锚点一致。[S05]

## 9. 质量门禁

正式面板必须满足：

- 正确风格签名；
- 角色身份未漂移；
- 主体、动作和关键道具通过 3 秒焦点测试；
- 角色剪影、表情和身体习惯有辨识度；
- 场景锚点未漂移；
- 道具形状与状态正确；
- 主光、环境光和材质逻辑可信；
- 人体、手、透视无严重错误；
- 无伪文字；
- 主体与文字安全区不冲突；
- 镜头与前后格有叙事变化。

任何硬失败项触发自动重生成；默认最多两次，仍失败则整次任务失败，禁止拿低质量图凑成品。

# 九大风格细分风格目录

本目录定义九个稳定 `style_id` 内部的 `substyles`。不要把这些子风格升级成第十个顶层风格；它们是 `variant_id` 的候选值，用来细化同一漫画传统内部的线条、版式、镜头、色彩和 QA 重点。

## 使用规则

1. 先用 `01_NINE_STYLE_MATRIX.md` 和 `presets/style_selection_matrix.json` 选顶层 `style_id`。
2. 再从该风格的 `selection.variants` 中选择一个 `variant_id`；它必须等于同一风格下某个 `substyles[].id`。
3. 编译 Art Direction / image prompt 时，把所选 `substyles[].prompt_additions` 合并到父风格 prompt；做 style proof 和正式 QA 时，把 `substyles[].qa_focus` 合并到风格专属 QA。
4. 用户没有指定子风格时，按书的题材、平台、情绪、动作强度和文化语境自动选择最贴合的一个；不要把多个互相冲突的子风格混在同一话里。
